# TalentScan — Job Eligibility & Salary Estimator

TalentScan is a modern vanilla JavaScript web application that evaluates candidate eligibility, estimates salary ranges, calculates confidence levels, and generates intelligent improvement suggestions using pure JavaScript fundamentals.

## Eligibility Rules

Candidate is eligible if:

- Age >= 18
- JavaScript Skill Score >= 60
- Projects Completed >= 2

Priority Candidate if:

- Skill Score >= 80
- Projects >= 3

Not Eligible if:

- Skill Score < 60
- Projects < 2
- Age < 18

---

## Salary Estimation Logic

| Skill Score | Salary Range |
|-------------|--------------|
| 60–70 | ₹4–6 LPA |
| 71–85 | ₹6–10 LPA |
| 86–100 | ₹10–18 LPA |

### Additional Bonuses

- Relocation = +₹1 LPA
- Postgraduate = +₹1 LPA

---

## Confidence Level Logic

| Projects Completed | Confidence |
|-------------------|------------|
| 4+ | High |
| 2–3 | Medium |
| Below 2 | Low |

## How To Run Locally

### Method 1 — Direct Run

1. Download the project
2. Open `index.html` in browser

---

### Method 2 — VS Code Live Server

1. Open project in VS Code
2. Install Live Server extension
3. Right click `index.html`
4. Click `Open with Live Server`

---

## How To Deploy On GitHub Pages

1. Upload files to GitHub repository
2. Go to:
   - Settings
   - Pages
3. Under "Build and Deployment":
   - Source → Deploy from branch
   - Branch → main
   - Folder → /root
4. Save changes
5. GitHub generates live deployment URL
